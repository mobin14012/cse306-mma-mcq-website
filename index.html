⚡ High-risk traps to memorize

  • 8086: 16-bit CPU, 20-bit address bus, 1 MB.
  • Physical = segment × 10H + offset.
  • Variable shift/rotate count = CL only.
  • TEST = AND for flags, no store; ZF=1 if zero.
  • LOOP auto decrements CX, repeats while CX≠0.
  • PUSH SP−2, POP SP+2.
  • Byte MUL: AX=AL×src. Word MUL: DX:AX=AX×src.
  • Byte DIV: AL=quot, AH=rem. Word DIV: AX=quot, DX=rem.
  • Unsigned DIV: clear AH/DX. Signed: CBW/CWD.
  • DOS: AH=1 in→AL, AH=2 out DL, AH=9 string DX + $.
  • 7-seg common-anode: 0 lights. LED common-cathode: 1 lights.
  • Dot-matrix: A=green, B=red, C=columns, A+B=orange.
  • LCD BF=1 busy → wait. Line1 80H, Line2 C0H.
  • .STACK 100H = 256 bytes (hex trap).
