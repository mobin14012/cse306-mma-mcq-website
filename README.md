# CSE 306 MMA Lab Quiz — MCQ Exam Prep Website

Microprocessor & Microcontroller Sessional (MIST) — 226 syllabus-filtered MCQs.

Live practice site in a single file: `index.html` (no build step, just open in a browser).

## Features

- All 226 MCQs grouped by topic section (A–G, H1–H4)
- Click an answer → instant feedback (green = correct, red = wrong + correct answer shown with explanation)
- Scoreboard: attempted / correct / wrong / accuracy
- Section filter, search, Review Wrong, reset per-section or all
- Progress auto-saves in browser localStorage
- High-risk traps cheat-sheet on top

## Run locally

Just open `index.html` in any browser.
